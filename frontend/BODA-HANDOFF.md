# 学校前端适配交接

本仓库提供版式、组件和素材，不含已验收的学校站群模板。正式接入仍需在学校博达后台完成配置；不能把静态 HTML 改名成 JSP 或把 Django 标签替换后就称为部署完成。

## 可复用材料

- `preview`：静态版式（本轮页数见 STATUS）及 css/js/assets，适合本地核对页面和素材。含新闻/通知/媒体的【演示】审核内容、普通空态、教师资料、来源说明及兼容版式页。学校发布需绑定真实资料源并替换演示，不能直接把审核HTML当作已审定内容上传。
- `src/data/columns.js`：栏目 ID、层级、旧 URL、栏目名称与集合类型；配置学校栏目时用作对照，不是博达栏目 ID。
- `src/templates`：头尾、教师卡片、栏目卡片、轮播和图片反馈的共享结构；参照 CONTRACTS.md 接入平台实际字段。
- `build-manifest.json`：文件来源、版本哈希和构建产物清单，便于核对本次素材包；它不是博达导入包。
- 字体许可证及 `docs/assets/site-media`：运行素材的来源/授权依据。未确认的素材仍需学校审核。

`backend` 和 content-catalog.json 只用于 Django 预览；SQLite、后台账号、服务脚本、sandbox、内部文档和个人资料均不属于学校前端上传材料。

用户已确认 icme.henu.edu.cn 可预览整站界面；新闻后台新增与首页/列表/详情联动尚未验证。博达实施分工暂缓，本轮只完成前端。可更新字段和平台待绑定项统一见 [维护对照](CONTENT-MAINTENANCE.md)。

## 学校试点顺序

1. 在学校平台确认站点权限、模板管理入口和平台帮助文档。提示缺少 `index.jsp` 说明首页模板尚未建立/绑定；仅下载 VSBBrowserHelper 不会自动生成模板。
2. 先建立并绑定首页模板，验证一份最小模板及本地 CSS/图片能经学校预览正常访问。具体组件标签、资源路径和插件使用方式以当前平台为准，不猜测。
3. 选“新闻通知 → 学院新闻”，用平台实际列表和文章组件做首页新闻预览、栏目列表、文章详情这条链路；绑定字段后检查标题、日期、摘要、图片、正文、分页、面包屑。
4. 通过学校允许的测试发布流程验证一条内容的新增、修改、撤下，核对旧链接、当前栏目、资源加载和移动端；取得证据后再扩展教师、集合、轮播和站点资料。
5. 确认最终域名、404/搜索/统一认证/页脚等平台能力，按学校流程审核上线。

## 仍需学校环境核实

后台栏目与资料源 ID、字段可用范围、组件语法、上传路径和缓存方式、是否允许本站脚本、图片/字体 MIME、首页和详情模板绑定、权限/审核配置。当前没有学校 API、SSO 或博达数据同步实现。本轮不登录、不配置、不发布学校站点。
