# 河南大学各学院官网技术栈、管理后台与栏目调研报告

- 调研日期：2026-10-09
- 调研目的：为「集成电路与微纳电子学院官网」项目（校级站群 vs 独立开发决策 + 栏目设计）提供依据
- 调研方法：WebSearch 确认官网与背景信息；curl 直接抓取各站响应头、首页 HTML 与主要栏目页（只读公开页面）；未使用任何登录、绕过或探测手段，后台信息仅来自公开文档与页面中公开可见的入口

## 一、校级站群体系总体情况（核心背景）

### 1.1 站群平台：西安博达软件「Visual SiteBuilder（VSB）」网站群

河南大学主站（https://www.henu.edu.cn/）与所抽查的全部学院子站均为**博达网站群系统**的站点，证据：

- 主站首页 HTML 含 `<!--Announced by Visual SiteBuilder 9-->` 注释（博达 VSB 9 版本标识）
- 每个站点首页均加载博达站群标配资源：
  - `index.vsb.css`
  - `_sitegray/_sitegray.js`（防复制/灰度化脚本）
  - `/system/resource/js/vsbscreen.min.js`（PC/移动端适配）
  - `/system/resource/js/counter.js` + `_jsq_(站点ID,'/index.jsp',...)`（博达访问统计）
- 新闻/文章 URL 统一为博达伪静态模式 `info/<栏目ID>/<文章ID>.htm`（主站、新闻中心、各学院均如此）
- 新版模板（2024 年平台升级后）普遍引入 Amaze UI（如 `skin/js/amazeui.min.js`，文学院、音乐学院；信息化办网站亦有 Amaze UI 提示字样）

### 1.2 统一基础设施（响应头特征）

所有站群站点（主站、news、latai、各学院）响应头高度一致：

```
Server: WebServer/X.X.X        ← 统一出口（实际 Server 头被统一改写，无法据此判断底层容器）
X-Frame-Options: SAMEORIGIN
X-XSS-Protection: 1; mode=block
X-Content-Type-Options: nosniff
Content-Security-Policy: default-src 'self' data: blob: *.henu.edu.cn ...（全校统一 CSP）
```

说明：域名、服务器、HTTPS、安全头策略均由校级统一管理，各学院站点共享同一套基础设施。

补充实测：抽查的 17 个学院站点（cs/ai/software/phye/bio/sofe/hdxc/lsxy/jjxy/energy/hcswyzyxy/future/latai/wxy/cm/sba/med）**HTTP 与 HTTPS 双协议均返回 200，未做 HTTP→HTTPS 强制跳转**；HTTPS 端点全部可用（含 future.henu.edu.cn）。证书由校级统一配置。

对照：校内业务系统（非站群）为独立技术栈，如选课系统 `http://xk.henu.edu.cn/cas/login.action` 返回 `Server: none` + `Set-Cookie: JSESSIONID=...` + `Content-Type: text/html;charset=GBK`（Java/Servlet 应用），与站群的 `WebServer/X.X.X` 明显不同。

### 1.3 站群管理后台：统一后台，无各院自建后台

河南大学信息化建设与管理办公室《网站群管理指南》（2025-10-27 更新，https://net.henu.edu.cn/info/1060/4978.htm）**公开记载**：

- 网站群后台管理地址：`http://hdcms.henu.edu.cn/system/login.jsp`（hdcms = 河大 CMS）
- 提供《网站群普通管理员使用手册.zip》下载、《网站管理员敏感信息排查手册》（net.henu.edu.cn/info/1071/5038.htm）
- 各学院网站管理员统一入「河南大学网站管理微信群」，分级授权（高级管理员/普通管理员）
- 咨询电话：开封校区 0371-23366678（郑老师）、0371-23366681（张老师）；郑州校区 0371-58525130（韩老师）
- 平台曾于 2020 年 12 月升级培训、**2024 年 4 月 15 日—5 月 30 日整体升级**（文件迁移 + 新闻迁移 + 新旧平台测试切换，见《关于河南大学网站群管理平台升级的通知》net.henu.edu.cn/info/1046/3836.htm）

即：**后台是全校统一的一套（hdcms），各学院只有账号和权限，没有自己的后台系统**。学院前台页面未发现任何独立后台入口。

### 1.4 统一身份认证（SSO）

- 河南大学统一身份认证体系：**CAS + OAuth 双协议**，认证账号与「网上办事大厅」一致（《河南大学信息系统集成标准规范》，net.henu.edu.cn 公开文档）。登录页须标注「使用河南大学统一身份认证账号登录」；集成时优先 CAS。
- 网上办事大厅（一网通办）：https://ehall.henu.edu.cn/（nginx + ywtb-portal 前端渲染 SPA，配置对象 `AMPConfigure` 疑似金智 Wiscom AMP 平台特征，**无法 100% 确认厂商**）
- 业务系统 CAS 登录入口 URL 模式示例：`https://kyfw.henu.edu.cn/caslogin.jsp`（科研系统）
- 相关入口：OA https://oa.henu.edu.cn/、WebVPN https://vpn.henu.edu.cn/（跳统一认证）
- 注意：站群内容管理后台（hdcms）与统一身份认证是两套体系；站群后台为网站管理员专用。

### 1.5 制度依据（对决策最关键）
《河南大学各级政务网站建设与管理基本规范（试行）》（2014-12-29 发布，net.henu.edu.cn/info/1057/3128.htm）规定：

1. **各单位二级站点统一使用河南大学网站群管理系统搭建**，域名统一由信息化管理办公室分配；
2. 开办二级网站须先向党委宣传部申请，批准后向信息化管理办公室申请域名、备案登记；
3. 服务器原则上在信息化管理办公室托管；
4. 信息更新期限不超过 30 天（超 30 天通报批评，超 60 天责令停办关闭网站）。

另有《信息系统建设与运维管理制度》同样要求各学院网站统一使用网站群系统，避免形成新的信息孤岛。

- 身份：河南大学**首批三个新工科学院之一**（另两个：新能源与智能制造学院、合成生物与制药工程学院）
- 背景：河南大学新工科「9+3」战略布局（9 个新工科学院 + 3 个研究院），2025-10-27 战略咨询会 → 2025-12-10 启动会 → 2026-05-09 首批学院揭牌暨院长聘任（郑州龙子湖校区）
- 学术带头人：**王家耀院士**（国家级高层次人才引领）；院长李正强（兼地理科学与工程学部副主任）
- 地址：郑州市明理路北段 379 号，河南大学科创西楼 B 座 4 楼（龙子湖校区），邮编 450046
- 培养体系：低空技术与工程（本科）、低空技术与空天工程（硕士）、航空宇航科学与技术（博士）

### 2.2 官网情况

- **官网存在**：https://latai.henu.edu.cn/（域名由主站「院系部门」页 https://www.henu.edu.cn/jgsz/yxbm.htm 官方链接确认，标注「低空技术与空天信息学院（筹）」）
- 首页 title：「河南大学低空技术与空天信息学院官网」

### 2.3 技术栈

- **属于校级博达站群**（证据：首页含 `<!--Announced by Visual SiteBuilder 9-->`、`index.vsb.css`、`/system/resource/js/vsbscreen.min.js`、`_jsq_(1001,'/index.jsp',...)`；响应头与主站完全一致 `Server: WebServer/X.X.X` + 统一 CSP）
- **但前端是高度定制模板**（站群内定制，非站群默认模板）：
  - 自定义资源：`css/style.css`、`js/site-shell.js`、`js/main.js`、`assets/`（hero 视频 `rocket-launch-hero.mp4`、海报图等）

  - **中英双语切换**（`data-lang-zh` / `data-lang-en` 属性 + JS 切换，全站每一段文案都有中英两版）
  - 页面为**纯静态 .html**（index/about/faculty/... .html，`data-page` 属性），非站群 CMS 动态栏目页
  - 页脚链接外部工作室 `ultraxlab.com`（疑为模板设计制作方；模板内残留 `news-template.html` 文件名，可佐证外部制作的静态模板套入站群发布）

## 五、对「集成电路学院优先走校级站群」的初步判断与建议

### 5.1 政策与现实层面：走校级站群是「默认且强制」的路径

1. 《河南大学各级政务网站建设与管理基本规范（试行）》明文规定二级站点**统一使用网站群系统搭建、域名统一分配、服务器原则上托管**；独立建站需要突破校级制度，且党委宣传部审批 + 信管办备案流程本身就导向站群。
2. 实际执行与制度一致：本次核实的主站 + 新闻中心 + 26 个学院/单位站点**全部为博达站群**，未发现任何独立建站特例。
3. 站群提供的域名、服务器、HTTPS、备案、等保、统一安全头（CSP/XSS/Frame）、备份、CDN 均随附，无需学院自筹；独立建站需自行解决全部合规事项。
4. 校级站群 2024 年刚完成整体升级（新平台），未来数年内不会废弃；新建站正好直接使用新平台。

### 5.2 独立建站仅有的合理动机，站群内也能满足

独立开发通常想要的是「现代化设计/定制交互」。但两条现成路径已证明站群内可以满足：

- **低空技术与空天信息学院（latai）**：站群内挂载**外部团队制作的现代静态模板**（hero 视频、Google Fonts、全站中英双语），完全脱离站群默认外观；
- **柔性电子学院（sofe）**：博达新版模板 + slick/anime 现代前端库定制（2023 年新建学院即如此建站）；
- **合成生物与制药工程学院（筹）**：博达新版 + AOS 动效 + Swiper + iconfont 深度定制。

即：**「设计自由」不构成独立建站的充分理由**，站群已能承载从「官方默认模板」（energy）到「全定制现代模板」（latai）的完整光谱。

### 5.3 建议

1. **主决策：优先走校级站群**（建议域名 `ic.henu.edu.cn` 或类似，须经信管办分配），这是制度要求下的最优解，也是 26/26 个已核实站点的一致选择。
2. **模板策略二选一**（按经费与工期定）：
   - **快、稳、省**：直接用博达官方新版模板（tpl-v2，参照 energy.henu.edu.cn），零设计成本，功能齐全（Vue 搜索/响应式/移动端），改版目录易维护；
   - **品牌优先**：参照 latai 模式，**外部设计定制模板 → 套入站群发布**（注意保持与站群统计、搜索、移动端脚本的兼容；latai 的教训是其静态页与站群 CMS 栏目体系脱节，新闻/通知需手工维护 html，**运维成本高**，须评估）。
3. **栏目设计建议**（基于 4.3 频率统计，按筹备期实际内容分期开通）：
   - **一期（必有，100% 学院都有）**：学院概况（简介/现任领导/机构设置）、师资队伍（按 高层次人才/教授/副教授/讲师/博士后 分层）、人才培养（本科/研究生）、科学研究（平台/团队/成果/动态）；
   - **二期（高频，87%）**：招生就业、党建工作、新闻动态、通知公告；
   - **三期（新工科学院建议强化）**：合作交流/产学研（新工科特色，对应 53%）、工程认证（工科特有，对齐 cs/software/energy）、学科建设；
   - **可选**：校友（47%）、下载中心/规章制度（40%）、联系我们、书记院长信箱；
   - **英文版**：47% 的学院有，且新学院普遍缺失、老学院多有失效（如 phye 已 403）。若学院有国际化定位，建议采用 latai 的**站内双语切换**（比独立英文域名 hdxcena/lsxyen 更易维护，避免另建一套站点导致内容不同步）。
4. **内容更新是硬约束**：校规要求 30 天红线（超 60 天责令关闭）。站群 CMS（hdcms 普通管理员）的流程化维护比自建系统更容易满足监管，也更利于多人协作与交接。
5. **动态功能走业务系统**：如需教师个人主页系统、招生系统、成果库等，作为独立业务系统申请并接入统一身份认证（CAS/OAuth），**前台信息发布仍归站群**——这是河南大学信息化的标准分工模式（对照组：选课系统 xk.henu.edu.cn 为独立 Java 应用，与站群分离）。
6. **对集成电路学院的特别提示**：
   - 该学院属「9+3」新工科布局中**尚未成立/筹建**的学院（2025-12-10 启动会已听取汇报），可参照**同批次的 energy / hcswyzyxy / latai** 三个已建站的新工科学院模板；
   - 最相关的对标是 **柔性电子学院（sofe，2023 建站，站内有"创'芯'大赛"）** 与 **纳米科学与材料工程学院（lab）**——二者均为站群内的新版模板 + 定制，可直接参考其栏目与做法；
   - **建议尽早向党委宣传部申请开办、向信管办申请域名**（域名资源需提前规划，ic.henu.edu.cn 目前尚未启用），避免成立时无站可用的被动。

## 六、调研局限与证据强弱说明

1. **站点抓取情况**：本次共核实 26 个学院/单位站点 + 主站 + 新闻中心 + 办事大厅 + 网站工作室，**全部可达，无一个站点抓取失败**；无需依赖搜索快照。未覆盖的学院（如数学与统计学院、化学与分子科学学院、农学院、法学院、外语学院、美术学院、体育学院、武术学院、文化旅游学院、药学院、哲学与公共管理学院、建筑工程学院、护理与健康学院、口腔医学院、基础医学院、教育学部、大学外语教研部等）仅从主站导航确认了域名存在，未逐一抓取页面。
2. **后端技术栈证据最弱**：所有站群站点的 `Server` 头均被统一改写为 `WebServer/X.X.X`，`X-Powered-By` 一律不存在，**因此无法确定底层 Web 容器、操作系统或开发语言**。本章所有「后端」结论均标注「无法确定」；仅在 URL 模式（`info/ID/ID.htm`、`*.jsp`、`ss.jsp`、`/system/...`）与老版 DWR 组件上可间接推断为 Java 系站群产品，但**未经直接验证**。
3. **后台信息仅来自公开文档**：站群后台地址 `hdcms.henu.edu.cn/system/login.jsp` 出自信管办公开发布的《网站群管理指南》，**未对该地址做任何访问尝试**（遵循「只记录公开入口、禁止探测」要求），其登录页实际外观、认证方式（是否走统一认证）**无法确认**。
4. **统一认证与站群后台的关系未验证**：站群后台是否为管理员专用本地账号、是否已接入 CAS，**无公开文档明确说明**；公开文档只证明校内业务系统（科研、采购、VPN、办事大厅）走 CAS/OAuth。
5. **办事大厅厂商判定为弱证据**：疑似金智 Wiscom（前端出现 `AMPConfigure`、`ywtb-portal` 等特征），**未经官方确认**。
6. **模板代际判断依据较软**：主要靠页脚版权年份、CSS/JS 库版本（Bootstrap 3、slick、SuperSlide、Vue）与目录命名（static/static1/static2、sy2022、index2026）推断，属**合理推断而非确证**；`Last-Modified` 只反映最后发布/生成时间，不等于建站时间。
7. **子代理结论已做部分复核**：主调研员复核发现两处需修正——① 未来技术学院 HTTPS 端点实测可用（子代理称「仅 HTTP」不准确，实为站内不改用 HTTPS 且不跳转）；② 物理与电子学院英文站 en-phye.henu.edu.cn 实测返回 **403 Forbidden（不可用）**，比「有英文版」更准确。其余子代理结论未逐条复核。
8. **栏目统计口径**：4.3 的频率统计基于各站导航可见的一级栏目归类合并（如「人才培养」合并了本科/研究生/继续教育等），不同站点的同一语义栏目名称不统一，统计存在主观归并成分，作趋势参考而非精确计数。
9. **低空经济学院信息**：官方准确名称为「低空技术与空天信息学院（筹）」，成立时间有 2026-04（官网自述）与 2026-05（百科/揭牌会）两种口径；「低空经济研究院」未检索到任何成立证据，但不能完全排除存在未公开机构。
10. **CDP 通道不可用**：Edge 浏览器未开启远程调试（需用户在 `edge://inspect/#remote-debugging` 手动勾选），Chrome 未安装，故本次**全部为静态层抓取**（WebSearch + curl + WebFetch）。高校站群对静态抓取友好，未遇到反爬拦截；但 JS 动态渲染内容（如部分导航、搜索结果）可能未被完整捕获。
11. **未做的事**：未尝试登录任何后台、未做端口/路径扫描、未提交任何表单、未使用任何绕过手段；所有后台与登录类 URL 均仅来自「页面中公开可见的链接」或「官方公开文档」。
