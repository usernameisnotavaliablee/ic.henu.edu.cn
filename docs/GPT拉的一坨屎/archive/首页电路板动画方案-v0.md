# 首页电路板动画：已确认方案与 v0 交付

日期：2026-10-10  
状态：已实现静态构图 v0；待用户确认画面后，在同一文件补齐动画 v1。

## 已确认方向

- 平面俯视、深色板面、元件错峰发光。不做透视、立体建模、投影或镜头旋转。
- 主题色 RGB(68, 116, 194)，即 `#4474C2`；蓝色变体仅调整 HSL 明度，其余使用黑白灰。
- 只做首页展示动画样片，不开发整站，不更改校级站群优先路线。
- 原创概念画面，不代表学院真实设备或电路工作原理。

## 已交付：构图 v0

文件：[circuit-pulse.html](./circuit-pulse.html)。直接用浏览器打开，完全离线，无依赖、无构建步骤。

- 16:9 平面画布：中央主芯片、两枚辅芯片、四枚电容、被动元件、直角/45° 走线与板边细节。
- 七个主要元件各为光波源。静态帧取首组脉冲启动后 780ms；相位分别为 0、110、250、340、180、400、70ms。
- 光波贴板面扩散；主芯片更强；使用普通透明度叠加，不使用加法混合或整屏增亮。
- 原生 HTML/CSS + Canvas 2D，静态板面缓存；窗口改变时重绘，像素倍率不超过 2，窄屏减少纹理细节。
- 可开关光波，折叠的 Tweaks 面板可调光强；未显示无效的播放、节律或进度控件。
- 无自动播放、定时器、逐帧动画循环。减少动态效果模式下同样保持静态。
- 内置原生自检：画幅、主题色、波源数量、错峰范围/唯一性、元件边界、波半径边界。每次打开自动执行；通过后根元素标记 `data-checks="passed"`。
- Canvas 不可用或 JavaScript 禁用时提供明确说明；不支持 Canvas 时隐藏无效控件。

预览图见 [previews/](./previews/)；浏览器验收记录见 [v0验收.md](./v0验收.md)。

## 构图确认后实现：动画 v1

- 默认 60 组/分钟，每组两次脉冲，间隔 160ms，第二次强度为第一次的一半。
- 保持固定 0–400ms 错峰，不逐帧随机变化；主芯片略强，其他元件较弱。
- 单道光波约 1.2 秒内向外扩散并淡出，限制交叠亮度。频率不是闪烁安全性的唯一判断依据。
- 播放/暂停与 6 秒循环进度条；拖动时暂停，恢复时从当前位置继续。
- Tweaks 仅保留节律与光强，节律范围 40–80 组/分钟。
- 减少动态效果偏好下默认静帧，可主动播放；页面隐藏时停止绘制，返回不补播。
- 补充周期、相位与循环连续性断言，以及播放/暂停、拖动、页面隐藏/恢复的浏览器验收。
