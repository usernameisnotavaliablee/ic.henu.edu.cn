## 本轮重做

文件：[circuit-pulse.html](./circuit-pulse.html)。原路径不变，浏览器刷新即可查看新版本。

1. **功能分区**：借鉴电脑主板的 CPU 插座、邻近供电区、内存区、扩展区、存储和板边接口布局；不再以少数大图标加放射线作为主体。
2. **主要结构**：CPU 插座框架、锁杆及密集触点；四条带卡扣与接触片的 DIMM 槽；三条 PCIe 槽；M.2 模组；芯片组散热结构；ATX 电源接口、SATA、USB/风扇/前置排针。
3. **细节层**：供电电感与电容阵列、小芯片引脚、贴片阻容、焊盘、过孔、安装孔、功能丝印与确定性板材颗粒。中性灰表面明暗只用于材质区分，不引入透视或投影。
4. **光感**：八个主要波源；双脉冲代表帧固定在 830ms；环形能量遮罩带亮局部铜走线，加少量柔和板面辉光，不再绘制锐利的完整圆圈。
5. **遮挡**：大元件会遮挡发光走线，避免走线亮光直接穿过插槽和外壳。全部使用普通透明度叠加，不使用加法混合。
6. **保留控件**：显示光波开关与 Tweaks 光强；键盘可用。仍不显示未实现的播放、节律和进度控件。

这是原创主板结构概念，不是厂商产品复刻、学院实物照片或可制造的电气设计。触点、布线、元件比例及数量均为视觉表达，不代表某型号规格。

## 绘制与验证

- 16:9，逻辑画布 1600×900；显示像素倍率上限 2，窄屏减少颗粒与部分小元件。
- 静态板面与铜走线分别缓存；仅在窗口尺寸和控件变化时重绘，无动画循环或自动请求。
- 每次绘制运行原生断言：主色、比例、波源、相位、元件锚定、波半径、关键结构是否完整，以及每段走线是否为直角/45°。
- 验收记录：[v02验收.md](./v02验收.md)。参考来源：[主板结构参考.md](./references/主板结构参考.md)。
