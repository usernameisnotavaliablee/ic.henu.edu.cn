## 用于构图的观察

- CPU 插座邻近供电电容、功率器件及散热结构。
- 内存槽成组排在 CPU 插座侧面，扩展槽布置在下半部。
- M.2、芯片组散热区域、RTC 电池及边缘接口形成不同的局部密度。
- 插槽触点、机械卡扣、排针、焊点、过孔与微小贴片元件，使主板区别于简化示意图。
