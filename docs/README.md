## 资料目录

- `发给老师/`：对外沟通材料，原有Word保持原样，不是运行源码。
- `内部资料/`：来源证据、教师公开资料与调研原件；不作为当前部署说明。
- `assets/`：素材来源、许可及字体母版。运行素材在`frontend/src/assets`；母版供重新生成字体子集，不直接加载到网页。
- `归档不再看/`：历史设计和状态，保留追溯；其中未完成项和提交状态不代表现在。

## 避免重复维护

`frontend/src`是前端修改入口；`frontend/preview`和`backend/templates/site/generated`是构建器输出，属于有意保留的运行产物，不手改、不各自维护一份。`frontend/examples`是审核样例，不是业务内容。本机试验、旧压缩包与运行数据保留在`sandbox`，不整目录交付。
