# 学院首页视觉语言

记录首页视觉设计中的专用术语；不包含实现方式或未确认的设计参数。

## Language

**首页电路板动画**：用于学院官网首页展示的电路板主题视觉，以芯片、电容等元件向外发光表现电路板的生命感。它不是学院真实设备、科研成果或电路工作原理的展示。

**元件光波**：从电路板上的元件向外扩散、具有水波观感的光亮变化。
_Avoid_：电信号仿真、真实电流可视化。

**心跳节律**：首页电路板动画中类似心跳的周期性发光节奏，不表示真实采集的生理数据。

**主板式构图**：借鉴电脑主板的功能分区和元件组合来组织首页电路板画面，不表示真实产品照片或可制造的电路方案。
_Avoid_：实物主板、工程设计图。
