# 完整源码与部署指引

`frontend/src`不能单独作为完整交付。完整包保留仓库结构，包含前端源码与构建器、静态成品、Django后端与迁移、依赖锁定文件、部署工具、文档、许可证及字体母版。

## 解压后看什么

| 目录 | 用途 |
|---|---|
| frontend/src | 修改页面、模板、样式、脚本、数据与素材 |
| frontend/scripts | Node构建及当前验证；archive内为退役脚本 |
| frontend/preview | 可直接打开的静态成品，构建自动生成 |
| frontend/examples、frontend/review.html | 可移植的审核样例和审核导航，不作为学校业务内容 |
| frontend/licenses | 字体许可证和子集清单 |
| backend | Django源码、模板、迁移、requirements.lock |
| deployment | 运行包生成、服务示例、备份与回退工具 |
| docs | 当前文档索引、素材来源、字体母版与明确标注的历史档案 |

完整包不携带Git历史、数据库、密码、服务器实际env、录音、安装器、个人资料、虚拟环境和临时测试目录。依赖通过锁定文件安装，不把本机环境复制给接收方。历史业务数据如需迁移，必须另行授权、备份和传输。

## 先查看静态页面

直接打开`frontend/preview/index.html`。本地HTTP预览可在解压根目录执行：

```sh
python -m http.server 8766 --bind 127.0.0.1 --directory frontend/preview
```

访问`http://127.0.0.1:8766/`。如修改源码，先执行：

```sh
node frontend/scripts/build-site.js
```

构建只使用Node内置模块，无需npm install；会同时更新静态页面和Django外框。更换标题字符需按[前端说明](../../../frontend/README.md)检查字体子集；母版和许可证已包含。

## 新环境运行完整Django站点

下面只适用于全新空数据目录。使用Python 3.12或兼容Django 5.2的版本；既有业务库按[后端交付文档](../../../后端交付文档_博达接入与预览部署.md)操作，不初始化覆盖。

Windows PowerShell，在解压根目录执行：

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r backend/requirements.lock
$env:IC_DATA_DIR=Join-Path (Get-Location) 'sandbox/new-data'
$env:IC_ALLOWED_HOSTS='127.0.0.1,localhost'
$env:IC_HTTPS='0'
$env:IC_PUBLIC_ONLY='0'
$env:IC_PORT='8095'
.venv/Scripts/python.exe backend/prepare_local.py
.venv/Scripts/python.exe backend/manage.py migrate --noinput
.venv/Scripts/python.exe backend/manage.py createsuperuser
.venv/Scripts/python.exe backend/manage.py collectstatic --noinput
.venv/Scripts/python.exe backend/manage.py check
.venv/Scripts/python.exe backend/serve.py
```

Linux/macOS使用`python3 -m venv .venv`，解释器替换为`.venv/bin/python`，环境变量改为：

```sh
export IC_DATA_DIR="$PWD/sandbox/new-data"
export IC_ALLOWED_HOSTS='127.0.0.1,localhost'
export IC_HTTPS=0 IC_PUBLIC_ONLY=0 IC_PORT=8095
```

然后执行同样的依赖安装、prepare_local、migrate、createsuperuser、collectstatic、check和serve命令。账号密码交互创建，不提供预设密码。访问`http://127.0.0.1:8095/`，后台`/preview-admin/`。新闻等业务内容初始为空，通过后台录入并发布；不要运行seed/bootstrap填充已有库。

## 部署到服务器

本包包括可部署的Django开发预览实现，服务默认仅监听回环。现有服务器使用[后端交付文档](../../../后端交付文档_博达接入与预览部署.md)中的release目录、独立数据目录、私有后台和只读前台方案；已有两个systemd单元及env示例可复用，真实配置不在包中。

```sh
python deployment/package_preview.py --check
python deployment/package_preview.py
```

后一个命令在`sandbox/deploy`生成运行包，不包含全部开发源码。新服务器仍需按实际域名、反向代理、账号和TLS配置，不能把运行包解压后就认为公网已上线。本轮只整理和验证本地交付，没有操作服务器。

## 学校博达

可复用静态页面、素材和共享结构，但本包不是博达一键导入包。`index.jsp`及栏目/详情模板需要在学校系统绑定资料源，步骤与待验证项见[博达交接](../../../frontend/BODA-HANDOFF.md)。

## 重建完整源码包

在带Git的原仓库根目录执行：

```sh
python deployment/package_source.py --output sandbox/deliverables/ic-college-full-source.zip
```

该脚本采用版本管理文件及明确的新交付文件白名单，拒绝包含数据库、密钥和本机运行目录；不运行部署，也不提交代码。同名文件存在时拒绝覆盖。包内`PACKAGE-MANIFEST.json`记录基线提交、实际文件SHA256及是否包含未提交整理；包旁有ZIP的SHA256。解压后以清单中的实际文件为准，不能仅按基线哈希声称工作区完全等于该提交。
