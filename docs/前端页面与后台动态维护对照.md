# 给学长：哪些地方需要接后台

学长，网站的栏目和页面样式已经基本定下来了。这次想请你帮忙把下面这些内容接到学校博达后台，让学院以后能自己换文字、图片、发文章，不用每次找我们改代码。

**菜单、栏目顺序、排版和动画先保持现在这样。后台主要负责改内容。** 比如可以新增一条招生通知、换一张教师照片，但不用做自由增删导航栏目的功能。

下面按页面列了需要管理的位置，点页面名字可以打开仓库里的预览。如果单独把这份文档发出去，链接需要配合项目文件才能打开；也可以直接在网站上按同名栏目找。

## 一、首页

打开[首页](../frontend/preview/index.html)，从上往下看：

| 位置 | 希望后台能做什么 |
|---|---|
| 顶部轮播大图 | 上传或替换图片，修改图上的标题、英文小字、说明和图注；调整顺序，暂时隐藏某一张。现在是六张，隐藏后下面的圆点和数量也要跟着变。图片暂时不增加点击跳转功能 |
| [学院新闻](../frontend/preview/index.html#home-news) | 从已发布的新闻中选哪些放首页、谁排在前面，最多显示 4 条。左边标题和右边图片要对应同一篇新闻 |
| [通知公告](../frontend/preview/index.html#home-notices) | 从已发布的通知中选择首页推荐、调整顺序，最多显示 3 条。标题、摘要和日期都从原通知读取 |
| [科学与创新](../frontend/preview/index.html#home-research) | 修改“从微观探索，到集成创新”这类介绍文字、下面的简短说明、研究平台和课题组入口旁的介绍，以及配图和图注 |
| 科研区下面的三张图 | 修改“走近晶圆与芯片”“微纳加工与实验”“认识半导体器件”的展示文字、图片、图注和图片来源。三个位置及原来的栏目跳转先不变 |
| [人才培养](../frontend/preview/index.html#home-education) | 修改“学有所思，研有所成”这类介绍文字、学科与专业及培养方案的简短说明、右侧图片和图注；入口仍指向原来的栏目 |
| [师资队伍](../frontend/preview/index.html#home-faculty) | 从教师名单里选择首页展示的人、调整顺序，最多 3 位；区块上方的说明也能改。照片、姓名、职称和简介直接用教师本人资料 |

首页不需要再录一遍新闻和教师资料。例如老师换了照片，首页、教师名录和个人介绍页都应该一起更新。轮播则单独管理。

科研和培养这两块目前是介绍文字加栏目入口，先保留这种形式，不改成“最新文章列表”。首页独有的短介绍可以单独编辑，内页已有的完整资料就直接共用。

首页推荐还需要接后台。**建议**没指定推荐时，新闻和通知按日期显示最新的，教师沿用现有顺序；指定推荐后优先显示推荐项，不够再补足。具体怎么在博达里配置，按平台方便的方式实现就行。

仪器页面只需要一个按钮跳到已有的服务平台，不需要在这个网站上新做预约系统。

## 五、师资队伍

这部分最重要的是：**一位老师只维护一份资料。**

后台需要能修改姓名、职称、照片、卡片上的简短介绍、完整个人简介、研究方向、教学科研经历、项目成果、公开邮箱/电话，以及显示顺序。个人介绍里的小标题、段落和列表也要能编辑，原有三位教师的完整资料要保留。

这份资料会用在以下几个地方：

| 展示位置 | 怎么使用 |
|---|---|
| [首页师资区](../frontend/preview/index.html#home-faculty) | 选择推荐到首页的老师，最多显示 3 位，同一个人不重复出现 |
| [教师名录](../frontend/preview/faculty.html#faculty-list) | 显示所有已发布的教师，没填人才类别的老师也要能找到 |
| [高层次人才](../frontend/preview/faculty-talents.html) | 按人才称号分组。一位老师可以有多个称号，每个称号可以填写获评年份 |
| [普通教师](../frontend/preview/faculty-teachers.html) | 显示明确归到普通教师这一类的老师；没分类不等于普通教师 |
| 个人介绍页，如[程纲](../frontend/preview/teacher-cheng-gang.html)、[郑海务](../frontend/preview/teacher-zheng-haiwu.html)、[张锦龙](../frontend/preview/teacher-zhang-jinlong.html) | 显示完整资料。首页卡片可以只显示几行简介，个人页不能因此把正文截掉 |

人才类别沿用现在的六类及顺序：国家级领军人才、国家级青年人才、河南省特聘教授、河南大学“黄河学者”/明德特聘教授、河南大学校特聘教授、河南大学百人计划。称号由学院提供，不根据履历自行判断。

前两类暂时没人时保留栏目标题和整理中提示，后四类没人时先隐藏。大头像、小头像和普通教师姓名列表的样式沿用现有页面。

## 六、新闻通知、党建、媒体和招聘

下面这些栏目可以尽量共用文章编辑方式：**标题、摘要、日期、来源、正文、图片、图注、附件。** 不同栏目各管自己的内容，点进去能看完整文章。

| 页面 | 需要注意的地方 |
|---|---|
| [学院新闻](../frontend/preview/news.html) | 和首页新闻共用。后台发一篇新闻后，可以选择是否推荐到首页 |
| [通知公告](../frontend/preview/notices.html) | 和首页通知共用，附件需要可以上传和下载 |
| [媒体掠影](../frontend/preview/media.html)里的[媒体报道](../frontend/preview/media-section-1.html) | 还要能填写媒体名称和原文链接，保留来源说明 |
| [党建党务](../frontend/preview/party-building.html)里的[党建动态](../frontend/preview/party-building-section-1.html)、[学习园地](../frontend/preview/party-building-section-2.html) | 分成两个栏目维护，各自显示文章列表和详情 |
| [人才招聘](../frontend/preview/careers.html)里的[招聘信息](../frontend/preview/careers-section-1.html) | 岗位、条件、申请方式、截止时间和联系信息可以放正文；本次没有要求做在线投递系统或自动到期下线 |
| [原服务指南](../frontend/preview/public-service.html)及[指南列表](../frontend/preview/public-service-section-1.html) | 保留已有页面和内容维护能力，不往主导航新加入口 |

## 七、联系我们，以及每页顶部和底部

| 位置 | 需要能改什么 |
|---|---|
| 每页顶部、底部的学院资料 | 正式院名、英文名称、校徽、校训。相同信息只维护一份，修改后全站一起更新 |
| 页脚备案信息 | 学校提供的正式备案文字；技术支持和工作室链接先保持现状 |
| [联系我们](../frontend/preview/contact.html) | 办公地址、公开电话、公开邮箱 |
| 联系页和页脚的公众号 | 二维码图片、名称、说明和是否显示；两处用同一份数据 |
| 联系页的官网二维码 | 独立上传二维码，修改名称、说明和是否显示，不与公众号混用 |
| 联系页的校内、校外链接 | 新增或修改链接名称、网址，选择分组、调整顺序、隐藏不用的链接 |
| [图片来源与授权](../frontend/preview/image-credits.html) | 换素材时能同步维护作者、来源链接和需要公开的授权说明；内部授权证明不用展示在网页上 |

二维码沿用现在的规则：公众号启用但没传图时保留“待提供”框，官网二维码没传图时先不显示；主动停用则隐藏。联系方式还没提供的地方不要编造。

[网站导航](../frontend/preview/site-map.html)根据既定栏目生成链接，不用让老师再录一次目录。[404 页面](../frontend/preview/404.html)保留现在的表情和文案，只需保证“返回首页”“网站导航”能跳到正确地址。

## 八、后台操作希望是这样的

比如老师要发一条通知：先写标题和正文、上传附件，保存成草稿；预览确认没问题，再按学校流程发布。发布以后，通知列表和首页推荐的位置才显示出来。

如果修改一篇已经发布的文章，**先保存的新稿不要直接覆盖线上内容**，等重新发布后再更新。需要撤下时，首页、栏目列表和详情页都不能继续公开这篇文章；如果已经接入搜索，搜索结果也要同步处理。谁能编辑、谁审核、谁发布，按学校的人员安排配置。

图片和 PDF 等附件希望能直接在后台上传、替换，不用老师先找地方上传再复制网址。图片要能写说明，附件要能改显示名称；允许的文件格式和大小按学校平台配置。正文至少能编辑段落、小标题、列表、图片、链接和附件。

还有几个显示上的要求：

- 没有内容的栏目，继续用现有的介绍和“相关内容正在整理中”，不把这些提示录成文章。现在标了“【演示】”的文章不能直接当正式内容上线。
- 新闻和通知通常按日期从新到旧，其他资料可以人工排序，制度优先按发布日期排列。首页推荐顺序可以和栏目里的顺序不同。
- 总览只显示前几条，不代表后台只能录几条。完整列表要能看全，有更多内容时能翻页；每页数量接入时再核定。
- 换图后各处引用要同步。删除可选图片、停用轮播或友链后，不要又把旧的默认内容补回来。轮播全部停用时的显示效果需要一起预览确认。
- 长标题、长正文、手机上的图片和附件也要试一下。列表里摘要可以只显示几行，详情正文要完整；教师照片别裁掉脸，二维码要能扫。

## 九、接完以后，我们一起检查这几件事

1. 发一篇新闻，从草稿、预览到发布走一遍，再检查首页、列表和详情是否一致。
2. 修改已发布文章，确认存草稿时线上不变；重新发布后更新，撤下后各处都不再公开。
3. 换一位老师的照片、职称和称号，确认首页、人才分类、教师名录、个人页一起变化。
4. 各栏目试着新增一条内容，检查总览、完整列表、详情；再试多条内容的排序和翻页。
5. 换轮播图片、调顺序、隐藏一张；再换联系方式、公众号二维码和友情链接。
6. 上传图片和 PDF，检查电脑、手机能否正常显示和下载。文件撤回后，旧下载地址是否还能访问，也请核对学校平台的处理方式。

可以先接公共头尾和新闻通知，再接教师、其他栏目、首页图文及轮播。最终希望上面列出的内容都能在后台维护。

目前前端页面和样式已经做好，但还没有完成这些内容与博达后台的绑定。推荐排序、多人才称号、图片附件上传等需要在平台上落实；遇到学校平台做不到或需要换一种实现方式的地方，我们再一起调整。
