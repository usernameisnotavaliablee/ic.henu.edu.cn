# IC 学院官网所需素材清单

> 用途：向学院老师收集官网建设素材时的**对照清单与进度表
> 制定日期：2026-10-09
>
> **使用方式**：先收「一、基础素材」→ 再按「二、栏目内容」分期收 → 用「四、进度表」跟踪 → 教师个人资料统一用「三、收集模板」发放。
>
> **优先原则**：以下栏目凡标注「**必有**」者，为其他 15 个学院实测 **100% 覆盖**的栏目，缺一项就会明显比其他学院单薄。

## 二、栏目内容清单

按调研的**栏目覆盖率**排序，分三期。**一期为上线必需**，二期建议同步准备，三期可后补。

### 一期：上线必需（覆盖率 93–100%）

#### 1. 学院概况 —— 覆盖率 **100%**

| 子栏目 | 需要的内容 | 状态 |
|--------|-----------|------|
| 学院简介 | 中文稿 + 英文稿（见基础素材 5） | ☐ |
| 现任领导 | 名单 + 分管 + 证件照 + 联系方式 | ☐ |
| 机构设置 | 组织结构图 + 各机构职责 | ☐ |
| 历史沿革 | **大事记时间轴**：筹建、批准成立、揭牌、学科获批、重要签约等关键节点 | ☐ |
| 院徽院训 | 见基础素材 2、3 | ☐ |
| 联系我们 | 见基础素材 8 | ☐ |
| 书记院长信箱 | 信箱地址或在线表单 | ☐ |

#### 2. 师资队伍 —— 覆盖率 **100%**

| 子栏目 | 需要的内容 | 状态 |
|--------|-----------|------|
| 高层次人才 | 院士、国家杰青/优青、长江学者、中原学者、河南省特聘教授等名单 + 简介 | ☐ |
| 教授名录 | 全体教授，逐人简介 | ☐ |
| 副教授 / 讲师 | 按职称分层，逐人简介 | ☐ |
| 在职教师 | 完整教师名单（姓名、职称、研究方向） | ☐ |
| 博士后 | 在站博士后名单 | ☐ |
| 荣休教师 | 可选 | ☐ |

> **每位教师需提供**：见「三、教师个人资料收集模板」。
> **调研提示**：多数学院有教师简介页，但只有 ai、hdxc、lsxy、jjxy 4 家做到「个人主页」级别。**建议至少做到每人一个简介页**（照片 + 简历 + 研究方向 + 代表成果 + 联系方式）。

#### 3. 人才培养 —— 覆盖率 **100%**

| 子栏目 | 需要的内容 | 状态 |
|--------|-----------|------|
| 本科教育 | 专业介绍、培养目标、主干课程、培养方案 PDF、学制学位 | ☐ |
| 研究生教育 | 学位点介绍（学硕/专硕/博士）、培养方案、导师信息、招生目录 | ☐ |
| 教学成果 | 教学成果奖、教改项目、一流课程、教材 | ☐ |
| 实践创新 | 实验室、实践基地、创新平台、学科竞赛获奖 | ☐ |
| 管理制度 | 教学管理相关制度文件 | ☐ |

#### 4. 科学研究 —— 覆盖率 **93%**

| 子栏目 | 需要的内容 | 状态 |
|--------|-----------|------|
| 科研概况 | 学院科研总体情况综述 | ☐ |
| 科研平台 | 重点实验室、工程研究中心、协同创新中心等（名称、级别、批准年份） | ☐ |
| 科研团队 | 各团队名称、带头人、成员、研究方向 | ☐ |
| 科研成果 | 代表性论文、专利、获奖、成果转化（可做列表） | ☐ |
| 学术交流 | 学术会议、报告、讲座动态 | ☐ |

### 二期：高频栏目（覆盖率 53–87%）

#### 5. 新闻动态 —— 覆盖率 **87%**

| 需要的内容 | 状态 |
|-----------|------|
| **学院成立相关**：批准文件、揭牌仪式、院长聘任、领导调研讲话 | ☐ |
| **科研动态**：论文发表、项目获批、成果获奖（建议首批准备 10–15 条） | ☐ |
| **学术活动**：会议、讲座、论坛 | ☐ |
| **学生活动**：竞赛获奖、文体活动、志愿服务 | ☐ |

> 每条新闻需：标题、正文、**配图（横构图）**、发布日期、撰稿/审核人。
> ⚠️ 调研中 2 家学院新闻是**纯文字列表无图**，视觉上明显弱——建议每条都配图。

#### 6. 通知公告 —— 覆盖率 **73%**

需要的内容：招生通知、学术会议通知、招聘公告、评奖评优公示、制度发布。

#### 7. 招生就业 —— 覆盖率 **87%**

| 子栏目 | 需要的内容 | 状态 |
|--------|-----------|------|
| 本科招生 | 专业介绍、招生计划、历年分数线、**招生宣传材料（含宣传片/海报）** | ☐ |
| 研究生招生 | 招生简章、专业目录、复试细则、导师信息 | ☐ |
| 就业信息 | 就业政策、招聘信息、就业质量报告、优秀毕业生去向 | ☐ |

> **提示**：本科招生主渠道是学校招生办，学院页面主要做**专业介绍与宣传**。建议向学院要一份「专业宣传文案」直接复用。

#### 8. 党建工作 —— 覆盖率 **87%**

组织建设、党建动态、理论学习、师德师风、工会工作。

#### 9. 学生工作 —— 覆盖率 **53%**

学生组织、团学建设、校园文化、实践创新、资助工作、心理健康。

#### 10. 合作交流 —— 覆盖率 **53%**

| 需要的内容 | 状态 |
|-----------|------|
| 校企合作 | 合作企业名单、共建协议、实习基地（如仕佳光子、汉威科技等） | ☐ |
| 产学研 | 技术合作、成果转化案例 | ☐ |
| 国际交流 | 国际合作院校、交流项目、国际会议 | ☐ |

> **新工科特色栏目，建议强化**——`latai`、`hcswyzyxy` 等新工科学院都重点做了这一块。

### 三期：可选/后补

| 栏目 | 覆盖率 | 说明 |
|------|--------|------|
| 校友专栏 | 47% | 校友名录、风采、捐赠；学院初创期校友少，可先占位 |
| English 版 | 47% | **建议用「站内双语切换」而非独立英文域名**（独立英文站易失修，phye 的英文站已 403） |

| 学科建设 | 20% | 重点学科、学位点、学科方向 |
| 人才招聘 | — | 岗位、条件、流程、联系方式 |
| 友情链接 | — | 国家自然科学基金委、河南省科技厅、中科院半导体所等 |
| 书记院长信箱 | 20% | 见一期 |

## 三、教师个人资料收集模板

- 可以直接重定向到该老师在其他学院的介绍页面也可直接做到本学院官网中
- **建议直接复制以下内容发给每位老师填写**，避免反复沟通。

```
【学院官网师资栏目资料收集】

1. 姓名：
2. 职称/职务：（如：教授、博士生导师、副院长）
3. 照片：请提供竖版证件照原始文件（蓝底/白底，长边≥1200px，勿用微信压缩图）
4. 学历经历：（本科/硕士/博士，起止年月、学校、专业、导师）
5. 工作经历：（起止年月、单位、职位）
6. 研究方向：（3–5 条关键词，或一段 100 字以内说明）
7. 主讲课程：
8. 荣誉与人才称号：（如：国家优青、河南省特聘教授、中原领军人才）
9. 学术兼职：（学会职务、期刊编委等）
10. 科研业绩：
    - 主持项目数及代表性项目
    - 发表论文数、代表性论文（3–5 篇，含完整出处）
    - 授权专利数
    - 获奖情况
11. 招生信息：招生专业、对学生的要求
12. 联系方式：办公电话、电子邮箱
    （⚠️ 手机号是否需要公开到网站？请明确）
13. 个人/课题组主页链接：（如有）
14. 是否同意公开上述信息：是 / 否
```
