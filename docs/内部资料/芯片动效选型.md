# 芯片动效选型

实施更新（2026-10-12）：已选择Magic UI的信号光流机制，使用原生SVG/CSS/JS自绘并统一替换首页、科研区、新闻示意及内页横幅。本轮重新读取MIT许可证并保存到 `frontend/licenses/magicui-MIT.txt`；未复制React组件，未引入第三方运行时。视觉和真实浏览器验收被自动审批服务503阻塞，当前不是用户已确认的最终外观。以下保留选型阶段的核查记录。

核查日期：2026-10-12。用途：为官网全站芯片视觉替换选型；本轮仅调研，未引入第三方代码、安装依赖或替换页面。

建议主选“简洁芯片结构＋沿线路流动的蓝白光束”，参考 Magic UI 的 Animated Beam 动效机制，用原生 SVG/CSS/JS 重新实现。它不是现成芯片作品，需要配合重新绘制的芯片视觉。备选 Aceyee/design-circuit 的电路光流，但只参考局部走线运动，不原样搬它的复杂主板和爆炸粒子。

当前未找到同时满足“现成精致芯片、轻依赖、可直接用于静态站、许可清晰”的即用项目。下面区分网页动效、素材生成工具和通用组件，避免把通用动画库说成成品。

## 下一步实现范围建议

- 首页：统一的细腻芯片主视觉，6—10 条蓝白光流缓慢移动，光束周期约 4—6 秒；不再增加满屏元件、标号和火花。
- 科研区：沿用同一套图形，裁切局部、降低运动强度；新闻示意图使用同套视觉的静态帧，明确是示意素材。
- 内页 Banner：使用同套芯片结构的局部纹理和一两条光流，不让每个页面加载独立 Canvas。
- 移动端：减少线路数量；离屏和页面隐藏时暂停；尊重减少动态效果设置，并保留静态后备图。
- 先做一张可运行小样确认构图，再全站替换。当前只是技术选型，不能据源码阅读宣称视觉已达到用户要求。

没有改动现有前端实现，没有提交或推送。报告可随主任务一并归档。
