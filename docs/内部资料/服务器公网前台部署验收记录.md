### nginx 站点关键内容

```nginx
server {
    listen 8099;
    listen [::]:8099;
    server_name 47.94.146.53 _;

    location ^~ /preview-admin/ { return 404; }   # 管理入口公网一律不可访问
    location = /preview-admin   { return 404; }
    location ^~ /static/admin/  { return 404; }   # 后台静态资源不对外

    if ($request_method !~ ^(GET|HEAD|OPTIONS)$) { return 405; }   # 只放行读方法

    location / {
        proxy_pass http://127.0.0.1:8096;         # 只代理只读实例，绝不代理 8095
        proxy_set_header Host              $host;
        proxy_set_header X-Forwarded-For   $remote_addr;   # 覆盖客户端伪造值
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

平滑加载方式：先 `nginx -t` 通过，再 `systemctl reload nginx`（**reload，不是 restart**）。

## 7. 回退方法

```bash
# 1) 撤掉公网入口（立即生效，不影响其他站点）
rm -f /etc/nginx/sites-enabled/ic-public
nginx -t && systemctl reload nginx

# 2) 关闭只读前台服务
systemctl stop ic-public-preview
systemctl disable ic-public-preview

# 3) 撤销防火墙放行
ufw delete allow 8099/tcp

# 4) 如需完全还原 nginx 配置（回到本轮修改前）
tar xzf /srv/ic-college/shared/backups/nginx-before-ic-public-20261012.tar.gz -C /
nginx -t && systemctl reload nginx

# 5) 阿里云安全组删除 8099/8099 入方向规则（控制台操作）
```

管理后台 `ic-preview.service`（127.0.0.1:8095）与隧道访问方式不受以上任何一步影响。

## 8. 尚未验证 / 遗留

- **HTTPS 未启用**：本阶段按用户要求先用 HTTP。443 仍由 FRP 占用。
- **手机真机 / 多尺寸 / 轮播等浏览器交互回归仍未做**：本机未安装浏览器自动化工具，
  按要求未擅自安装。外网验证是 HTTP 层面的（状态码、链接、内容），**不代表视觉与交互通过**。
- 专项安全验收未做。25 项测试全绿不等于安全验收通过。
- 业务库备份恢复演练未做。
- 公网前台目前是 **HTTP 明文 + 无访问口令**，只要知道 IP 和端口即可访问——符合"给朋友直接看"的要求，
  但也意味着内容对全网可见。若之后要收敛，需加 HTTPS 与访问保护。
- 后台人工验收清单见[预览后台人工验收清单](预览后台人工验收清单.md)。
