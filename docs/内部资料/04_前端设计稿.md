## 1 栏目结构

已核对低空源码 src/data/site.js：科学与创新、人才培养、师资队伍、公共服务、关于我们、联系我们、招聘；新闻通知还有单独列表与详情模板。IC参考其结构，将“关于我们”显示为“学院概况”，保留新闻通知入口，不复制低空学科事实或旧栏目编号。

| 一级栏目 | 首版内容 | 无资料时 |
|---|---|---|
| 学院概况 | 简介、办学定位；领导/机构为后续子栏目 | 明确写“学院资料待补充” |
| 科学与创新 | 研究方向、科研项目、创新成果 | 留标题和内容框，禁止填造科研成果 |
| 人才培养 | 专业课程、培养方案、实践培养 | 保留版式，不推断已有招生层次 |
| 师资队伍 | 张锦龙、郑海务、程纲三位现有底稿与照片 | 标注名单及资料待审核 |
| 公共服务 | 平台服务、合作交流；具体业务待学院确认 | 标为栏目占位，不沿用无人机培训等低空业务 |
| 新闻通知 | 新闻和通知列表、通用详情页 | 使用“标题示意”，不虚构日期和报道 |
| 联系我们 | 学院地址、电话、邮箱 | “待提供”，不放假号码 |
| 人才招聘 | 经学院确认的招聘信息 | 预览标“资料待补充”，不虚构招聘岗位 |

校院标识链接返回首页。桌面采用顶栏导航，手机采用可关闭菜单；栏目变多时先切换手机菜单，避免挤压或横向滚动。今晚示意页用页内锚点验证栏目布局；实现阶段分别建立栏目页，并共用列表/详情模板。

## 2 首页与内页布局

首页：校院标识与导航 → 芯片首屏 → 新闻通知 → 学院概况 → 科学与创新 → 人才培养 → 师资队伍 → 公共服务与招聘入口 → 联系方式。内页统一使用栏目标题、面包屑、正文/列表和页脚，避免每个栏目另做一套。

无资料可以先占位，只供内部演示。正式发布时替换为审定内容，空栏目按学院意见隐藏或使用经批准的提示；发布前检查所有“示意、待提供、待接入”标记，不把示例当成真实新闻。

## 3 视觉和芯片动效

主色深蓝 #0B3263、科技蓝 #2563EB，辅以浅蓝和白色，突出学院的集成电路与微纳电子方向。已有[精细电路板样片](电路板样片/首页电路板动画方案.md)保留作为动效细节参考，其完整动画尚未实现；当前轻量SVG示意不代表该样片已完成或已被用户替换。用户已确认宋体、不加粗只用于Word和交接文档；网页采用适合屏幕阅读的字体和适度字重。校徽、院徽必须使用正式素材，当前校名字标只是临时显示。

首屏使用自绘SVG芯片、引脚和电路线，CSS实现轻微浮动与流光，不引入大型三维库或视频。提供暂停按钮；遵循prefers-reduced-motion。手机缩小图形、减少视觉干扰，标题和操作按钮保持静止。

首页图片新闻与首屏主题轮播分开。轮播功能在有真实多图素材后实现：单图静态，多图默认6秒切换，支持手动操作和暂停；当前示意页只有芯片动效，不声称已做多图轮播。

## 4 页面架构与内容入口

- 采用HTML/CSS/少量JavaScript，不为了设计稿另建SPA。公共头尾、导航、新闻列表、教师卡片和占位提示复用。
- 正式模板参考低空的 src/templates、src/content、src/data 和博达发布包结构；开发预览由Django提供数据，学校正式版由博达组件提供数据。
- 页面结构保持一致，两种内容来源分别适配；不将Django标签直接混入学校JSP，不设计未经证实的REST或SSO接口。
- 新闻标题、日期、摘要、配图、链接与分页按博达变量接入，IC栏目ID未知时留空。教师、轮播和固定页面如何维护，等取得学校账号后核实组件能力。
- 对用户没有作用的接口状态、安全检查和演示说明仅放在设计审阅工具栏；正式官网移除该工具栏。未知后台入口不能伪装成登录成功。

## 5 手机适配：设计和开发同步完成

不留到整站完成后补救。设计先定义窄屏布局，开发每个组件时一起实现，最终再做真实手机浏览器复核。

| 部分 | 桌面 | 手机 |
|---|---|---|
| 导航 | 横向菜单；宽度不足提前切换 | 可关闭的折叠菜单，支持键盘和返回焦点，不仅依赖悬停 |
| 首屏 | 文字与芯片分栏 | 上下排列、芯片缩小、文本保持可读 |
| 新闻与通知 | 图片新闻与列表分栏 | 单列、长标题换行，切换按钮易点击 |
| 教师 | 三列卡片 | 单列，不拉伸人像 |
| 详情 | 有限正文行宽 | 正文图片不溢出，宽表格在自身容器滚动 |
| 动效 | 轻量SVG/CSS | 支持暂停和减少动态效果，不能拖慢滚动 |

验收宽度：320、375/390、768、1024、1440像素；页面主体无横向滚动，点击区尽量至少44像素，保留缩放，不设置user-scalable=no。实际学校模板上线后复测一次。仅有viewport与移动端脚本不算验收。

## 6 搜索与栏目优先级

本轮基础必做：学院概况、师资、人才培养、科学研究、新闻、通知，以及联系方式。新闻和通知共享模板。招生就业、党建先保留配置位置；公共服务、人才招聘参照低空保留简单占位。任何后续业务功能须有实际内容与需求，不因参考站存在而照单全做。

搜索先预留入口和结果页版式，正式优先接学校组件。低空搜索框本身未实现查询；本轮不自建全文检索、分词或PDF搜索。若用户要求今晚可用，可在已批准的预览内容中查询标题、摘要与教师姓名；该功能与学校正式搜索分别验证。未接通的公开入口隐藏，不能让访客提交后无响应。

详细取舍、源码证据和待判断事项见[调研提取](02_官网调研报告.md#八本轮基础开发必做调研提取与最新源码复核)。

## 7 今晚交付顺序与检查

先做首页及八个栏目位置，再补通用列表/详情模板；全部共用一套蓝白样式与内容字段。教师先使用现有资料，缺内容用占位，以可展示、可替换为完成目标。

检查桌面和手机布局、菜单开合、新闻通知切换、图片比例、长标题、锚点及暂停动画；减少动画偏好下应静态显示。设计示意通过不代表真实学校新闻已接通，当前交互和手机测试仍需在实施阶段逐项记录。
