# 前端设计稿（B 蓝白基础版）

更新：2026-10-12。学院正式名称：河南大学集成电路与微纳电子学院。按最新要求先交付基础版，队友随后美化。宋体、不加粗用于Word和交接材料，网页使用适合屏幕阅读的字体。

当前入口：[基础版首页](../frontend/preview/index.html) · [队友修改说明](../frontend/README.md)。本稿与[安全设计稿](05_安全设计稿.md)并列；后端、SQLite与学校后台安排见[实施总计划](03_设计开发实施计划.md)。

## 1 页面结构

采用学院官网常见结构：校院标识行 → 独立整栏导航 → 通栏Banner轮播 → 学院新闻与通知 → 科学与创新/人才培养 → 师资 → 普通服务入口 → 联系页脚。

标识与导航分为两层，桌面导航占满整个蓝色横栏，在居中内容区均匀分布。手机把导航改为可开关菜单；无JavaScript时仍能看到导航。旧版右上角菜单和芯片分栏首屏不再作为当前方案。

## 2 栏目和页面

参考已解压的低空 src/data/site.js。首页外保留八个一级栏目；各栏目有独立页面，不再仅用首页锚点。

| 栏目 | 首版处理 |
|---|---|
| 学院概况 | 简介、组织机构占位 |
| 科学与创新 | 研究方向、科研平台与成果占位 |
| 人才培养 | 学科专业、课程与培养方案占位 |
| 师资队伍 | 三位教师照片与姓名预览；详情正文待审核 |
| 新闻通知 | 新闻列表、通知列表、共用文章版式 |
| 公共服务 | 简单信息占位 |
| 人才招聘 | 简单信息占位，不虚构岗位 |
| 联系我们 | 正式名称；地址、电话、邮箱待提供 |

当前共20个静态页面。示例新闻不填假日期、假来源；教师不填未审核职称和履历。缺资料的位置明确显示“待提供/待审核”。招生就业、党建等暂不铺设空的多级菜单。

## 3 Banner和视觉

保持B方案蓝白配色。基础版主色为深蓝 #123e70，辅助浅蓝、白色；样式变量统一放在 frontend/src/css/style.css 顶部，队友可直接替换。

Banner先用图片轮播：学校牌坊照片＋原创芯片电路SVG。牌坊是校园示意，不冒充学院建筑；图片来自低空参考包，720×406的原图仍需换高清正式素材。校徽同样来自参考包，正式使用以学校素材为准，不借用低空院徽。

两张图默认每6秒切换，提供前后按钮、圆点和暂停。焦点进入、鼠标悬停、页面隐藏时暂停，系统减少动态效果偏好下静态显示。芯片图仅加轻量光带，队友后续可换为更精细动效；视频本轮不做。

## 4 工程与站群接入位置

HTML/CSS/少量JavaScript，使用现有Node内置模块构建，无npm依赖。沿用低空 data/templates/content 组织方式及模板替换函数，改为构建时拼接头尾，让导航在禁用脚本时也可用。

| 位置 | 用途 |
|---|---|
| frontend/src/data/site.js | 文案、导航、轮播、教师及未知学校配置 |
| frontend/src/templates/partials/ | 公共头尾 |
| frontend/src/content/home.html | 首页模块 |
| frontend/src/css/style.css | 样式和响应式布局 |
| frontend/src/js/main.js | 菜单与轮播 |
| frontend/preview/ | 可直接打开的生成页面 |

博达适配保留 home-news、home-notices、news-list、notice-list 插入位；article-content是本地文章正文位置。后续依据学校真实组件输出替换，不把本地静态文件名当成正式文章地址。未知账号入口、站点和栏目ID保持空值；当前没有接通学校平台，也未生成经后台验证的JSP发布包。

搜索、英文版和后台登录未接通时不展示假按钮。正式搜索优先用学校组件，前台不自研学校SSO。Django和SQLite继续保留在后续开发预览计划中，本基础前端不依赖它们。

## 5 手机适配

随首版组件实现，不留到美化之后。低于960像素折叠菜单，600像素以下新闻、科研/培养、教师和服务入口改为单列。图片不超过容器宽度，正文可换行，不禁用页面缩放。Escape关闭菜单并把焦点还给按钮。

计划验收宽度：320、390、768、1024、1440像素。除了主体无横向溢出，还需检查菜单点击、焦点、轮播、正文图片和长标题；手机真机与学校模板部署后各复核一次。

## 6 已检查与交接

Node构建与脚本语法通过；20页的398处本地资源和链接引用通过，未发现失效片段与重复ID。首页已在浏览器通过本机HTTP加载并读取导航、轮播控件和内容结构。

手机各尺寸视觉、逐项交互、减少动态效果及真机验收仍待复核，不把已编写响应式CSS当成全部验收通过。静态页面通过也不表示新闻发布、审核、搜索或学校统一认证已接通。

下一步由队友在src中美化、替换经审定素材，再运行构建；不要直接修改preview中的生成页面。当前基础前端未部署公网，未改原有服务器站点。
