# Claude Code 公网前台预览交接提示词

请继续当前 IC 学院官网项目。这一阶段我需要把服务器上已经部署的前台开放为公网预览，让朋友直接用浏览器访问，不需要 SSH 隧道，也不需要登录；测试后台仍保持私有。

1. 优先希望地址为 `http://47.94.146.53/`。先核查服务器现有 80 端口和 nginx 路由；如果该地址已被原网站使用，不要覆盖、迁移或中断原站，改用经检查空闲的独立公网端口，交付形如 `http://47.94.146.53:实际端口/` 的地址。公网 IP 加端口我可以接受。这一步先用 HTTP 展示公开前台，不要求为了演示配置域名或证书。
2. 复用现有 `/srv/ic-college` 的代码、虚拟环境和 SQLite，优先启用仓库已有的独立只读前台服务 `ic-public-preview.service`（`IC_PUBLIC_ONLY=1`，计划监听服务器 `127.0.0.1:8096`，先检查占用），再由 nginx 提供公网入口。展示后台已批准的新闻、通知和现有静态页面，草稿不得公开；后台批准更新后，公网前台也要更新。核对公开实例配置与 Host 配置，使临时 HTTP 入口不会被旧 HTTPS 设置重定向到不可用地址。
3. 私有管理服务 `ic-preview.service` 继续只监听服务器 `127.0.0.1:8095`，不能改成公网监听，也不能把公网入口代理到 8095。公网访问 `/preview-admin/` 及其子路径应返回 404，写请求应被拒绝，数据库、凭据与配置文件不得作为静态文件公开。我现有的电脑本机 `http://127.0.0.1:8095/preview-admin/` 管理方式可以保留 SSH 隧道；“不要 SSH 隧道”只针对朋友访问前台，并不要求变更后台访问方式。
4. 保持原网站及既有服务正常，尤其不要干扰现有 FRP 的 443 端口。我授权实施本次必要的项目服务、nginx 隔离配置和所选前台端口放行；不要关闭整个防火墙。修改前保存可回退配置，nginx 配置检查通过后再平滑加载。若云安全组需要我在控制台操作，请给出具体端口、协议和规则位置，不要因为 curl 本机成功就宣布公网已通。
5. 优先复用服务器现有环境，本机不安装新环境。确实需要新增系统包或 Python 依赖时，先说明用途和位置并与我确认；本机开发工具仍按 `C:\Develop` 的约定。Git 提交推送、专项安全验收继续暂缓，但本次公网前台与私有后台的隔离必须验证。
6. 实际检查公网入口的首页、新闻和通知列表、已批准详情、其他静态内页及图片/CSS/JS；检查未批准内容不可见、管理入口不可访问、写请求被拒绝；确认原网站仍正常。以外部网络访问结果作为公网可达证据；没有外部测试条件时明确标注“待手机流量或朋友网络验证”，不要把服务器内部请求算成外网验证。
