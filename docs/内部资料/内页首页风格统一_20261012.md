# 内页与首页视觉统一

后续修正见 [学院概况、字体与内页背景字修正](学院概况与字体动效修正_20261012.md)：已补学院概况、英文、字体字符覆盖及背景字呼吸，本页记录为上一轮结果。

本轮只修改本地代码，未部署、未提交和推送，业务库未改动。

## 实现

- 21 类集合概览复用首页 editorial-heading、楷体标题和左右交替 section-watermark。
- 概览白色与首页研究区同款 #f3f6fa 全宽交替；撤掉淡绿淡蓝面板、彩色顶线和“探索与了解／信息与动态”小标签。
- 科研、人才培养、公共服务的相关入口移至页尾紧凑导航；集合概览移除头部重复占位大图。原栏目与相关入口保留。
- 单子栏目列表不再显示只有一项的重复侧栏。新闻、通知、媒体保留必要的三类切换。
- 桌面概览复用首页滚轮结束后的平滑对齐；仅在分区边缘附近生效。长内容中段、文章列表、详情、触屏及减少动态效果模式不强制吸附。
- CSS 版本 20261012-12，main.js 版本 20261012-5。静态构建与 Django 模板同步，栏目元数据增加装饰字段，无数据库迁移。

72 页构建，5557 个引用检查，95 项结构检查，45 项 Django 测试，226 文件打包检查通过。
