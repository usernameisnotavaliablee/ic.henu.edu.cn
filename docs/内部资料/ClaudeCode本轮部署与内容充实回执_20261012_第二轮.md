## 6. 后台录入及发布方式

**全部通过后台网页完成**：Playwright 驱动真实浏览器登录 →
「教师、栏目与站点资料」→ 新增栏目条目 → 选择"所属列表栏目" → 填写标题／摘要／正文／日期／配图／排序
→ 保存草稿 → 在列表勾选后执行"**将所选资料发布到预览前台**"。

- **未使用** SQL、ORM 脚本、`seed_showcase`、管理命令、接口直灌或替换数据库文件。
- 演示正文**未固化**进 HTML、JS 或构建数据文件。
- 驱动脚本与内容草稿放在 `sandbox/`（已 gitignore），**不是应用代码，不进部署包**。
- 顺序上**先建并发布"研究方向"，再建"课题组"并关联方向**——方向下拉只列已发布的条目。

条目地址标识统一使用 `entry-` 开头（如 `entry-career-resume-ability`），创建后固定。
固定位置（学院简介、组织机构、领导班子、站点信息）通过同一入口选择对应位置维护。

**过程中遇到并解决的问题**：① 配图选项只接受 jpg/jpeg/png/webp，首轮草稿中的 `chip-banner.svg`
不在下拉内导致保存中断，已按主题重新分配为可用图片；② 站点信息表单需要带 `?key=site` 参数打开
才会渲染对应字段，已修正。两次问题均已修复并重跑，**最终录入 0 错误**。
