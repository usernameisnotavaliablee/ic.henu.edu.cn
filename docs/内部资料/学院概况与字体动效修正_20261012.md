# 学院概况、字体与内页背景字修正

## 后续调整：优先访问者本地楷体

用户查看截图后提出使用访问者本机字体。样式版本已更新为 `20261012-14`，全站楷体区域统一按 `KaiTi → 楷体 → Kaiti SC → STKaiti → KaiTi_GB2312 → IC WenKai` 选择。浏览器按字体名称匹配已安装字体，无需读取任意本地文件或申请文件访问。没有安装楷体的设备仍使用网站自托管开源楷体，不要求用户安装字体。
