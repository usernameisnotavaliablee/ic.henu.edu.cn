# 网站可视化编辑器使用说明

`editor/` 是网站可视化编辑界面，适用于 64 位 Windows 10/11 和常见 x86_64 Linux 桌面系统。推荐使用项目生成的免安装便携包：包内自带本地运行环境，不需要另外安装 Python、Node.js、PHP、数据库，也不会直接上传文件到服务器。

## 便携版启动

1. 完整解压 `release/河南大学低空学院网站可视化编辑器-便携版-Windows-Linux.zip`。
2. Windows 双击 `启动编辑器-Windows.bat`。
3. Linux 双击或运行 `启动编辑器-Linux.sh`。
4. 浏览器会自动打开并载入包内 `dist/`；命令窗口应保持开启。

便携版只监听本机地址 `127.0.0.1`。如果浏览器没有自动打开，启动窗口会显示可手动访问的地址。

## 开发模式启动

开发人员也可以在项目根目录运行：

```bash
python3 -m http.server 8000
```

打开 `http://127.0.0.1:8000/editor/`，点击“选择 dist 文件夹”并选择项目中的 `dist/`。也可以在“发布目录地址”中填写 `../dist/`，点击“读取地址”。此开发模式仍只导出文件，不直接写回项目。

如果浏览器不允许直接选择文件夹，可使用 Chromium 系浏览器从 HTTP 地址打开编辑器；通用浏览器仍可选择文件夹并导出更新包。

## 编辑与导出

- 双击页面中的可见文字，输入新内容，按 Enter 或点击其他位置保存。
- 点击页面图片选中它，再在本地选择新的 JPG、PNG、GIF、WebP 等图片。如果浏览器拦截了文件窗口，点击工具栏“替换所选图片”。
- 使用“自适应”“1280px”“390px”检查桌面和移动预览。
- 便携版点击“保存到本地并导出”：先把修改写入包内 `dist/`，再下载只含本次改动文件的 ZIP 更新包。
- 开发模式点击“保存 / 导出”：只下载更新 ZIP，不写入项目。

导出包中的路径就是服务器覆盖路径。例如 `about.html` 上传到网站根目录，`js/site-shell.js` 上传到网站根目录的 `js/`，图片上传到 `assets/`。

## 修改范围

页面正文文字或正文图片只生成当前页面的 HTML；公共页头、导航、页脚或电话只生成 `js/site-shell.js`。图片替换还会生成图片文件，确保上传后引用不丢失。未修改的页面不会进入更新包。

便携版会持续保存自己的 `dist/` 工作副本，因此关闭后重新启动可以继续上次修改。每次保存前的旧文件位于便携包 `.editor-data/backups/`。不要重新解压覆盖正在使用的便携包，否则工作副本会恢复到初始版本。

便携版还会保留累计“待上传文件”清单。重新启动后可以直接再次导出，更新 ZIP 会包含之前尚未处理的保存文件以及本次新修改，避免跨会话漏传。

编辑器不会回写开发仓库的 `src/`。发布确认后，如需继续使用模板构建流程，请手工把修改同步到对应源码，再运行：

```bash
node scripts/build-site.js
node scripts/verify-site.js
```

这样可以避免下一次完整构建覆盖编辑器导出的内容。`.backup/` 备份应在人工验收完成前保留。

## 安全与回滚

便携服务仅允许写入包内 `dist/` 的网站文件，并在覆盖前保存本地备份。上传前仍应备份服务器现有文件；需要回滚时，可使用服务器备份、便携包 `.editor-data/backups/` 或上一份导出包恢复。
