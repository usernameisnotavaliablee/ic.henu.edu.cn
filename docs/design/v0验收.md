## 可重复执行的原生自检

直接在浏览器打开 `circuit-pulse.html` 即自动执行自检。通过时：

```javascript
document.documentElement.dataset.checks === 'passed'
```

自检失败会抛出带 `Circuit v0:` 前缀的错误。覆盖画幅、主色精确值、波源数量、相位范围及唯一性、元件边界、半程波半径和负值/超时钳制。

浏览器截图位于 `previews/`：板面、桌面、平板、手机。
