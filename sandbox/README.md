# 仓库内运行沙盒

本目录仅此说明纳入 Git。Python 环境、依赖缓存、临时浏览器资料、数据库、密钥、凭据、日志与部署压缩包均保留在本目录且被忽略。

**各平台自建，不要求两人布局一致。**以下为约定名称（本机实际存在哪些子目录见各自本地的 `AGENTS.md`，不入库）：

- `.venv/`：Python 独立环境，不改变本机全局 Python。Windows 在 `Scripts/`，macOS/Linux 在 `bin/`。
- `data/`：SQLite、独立密钥和后台静态资源。
- `tmp/`：本次测试临时文件；不得存放正式内容。
- `pip-cache/`：仅本项目安装缓存。
- `deploy/`：白名单部署包与哈希清单，不包含数据库、密钥和运行环境。
- `access.txt`：首次初始化后生成的本地管理账号，只在本机查看，不发送给老师、不提交。

源码与操作入口：[后端交付文档](../后端交付文档_博达接入与预览部署.md)。当前运行结果以[验收证据](../STATUS.md)为准。
