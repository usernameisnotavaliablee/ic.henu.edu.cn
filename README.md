# 河南大学集成电路与微纳电子学院

## School of Integrated Circuits and Micro-Nano Electronics, Henan University

本仓库是学院官网的**开发预览版**。正式官网仍走**学校博达站群**；本项目用于团队内部开发与演示，
不与学校站群自动同步。
